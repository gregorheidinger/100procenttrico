# 100% Trico

Website voor zangtrio **100% Trico**.

De eerste versie is bewust opgezet als een snelle, statische website zonder build-stap. Daardoor kan de site eenvoudig via GitHub Pages, Netlify of Vercel worden gepubliceerd.

## Bestanden

- `index.html` — inhoud en structuur
- `styles.css` — vormgeving en responsive layout
- `script.js` — mobiel menu, animaties en jaartal

## Later toevoegen

- Definitieve promotiefoto's
- Live foto's
- Video('s) of embeds
- Definitieve boekings/contactgegevens indien gewenst
- Eigen domeinnaam

## Publiceren met GitHub Pages

Ga in GitHub naar **Settings → Pages**, kies **Deploy from a branch**, selecteer `main` en `/ (root)` en sla op.
